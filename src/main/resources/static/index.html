Mandatory Section 2 Compliance
Concept A

Encapsulation

Implemented in the Patient class using private fields (#patientId, #patientName, #age, #gender, #phoneNumber). Direct external access to private properties is strictly prohibited by JavaScript runtime. Controlled access and data validation are provided via public getters and setters. 

class Patient {
  #patientId;
  #patientName;
  #age;
  #gender;
  #phoneNumber;

  get patientName() { return this.#patientName; }
  set patientName(name) {
    if (!name || name.trim().length < 2)
      throw new Error("Invalid name");
    this.#patientName = name.trim();
  }
}
Concepts B & C

Inheritance & Abstraction

Abstract parent class LabTest prevents direct instantiation (new.target === LabTest) and defines the abstract contract method processTest(). Concrete child classes BloodTest, UrineTest, and ImagingTest extend LabTest. 

class LabTest {
  constructor(...) {
    if (new.target === LabTest)
      throw new Error("Cannot instantiate abstract class LabTest.");
  }
  processTest() {
    throw new Error("processTest() must be implemented.");
  }
}
class BloodTest extends LabTest { ... }
Concept D

Polymorphism (Runtime Overriding)

Each subclass overrides processTest() with distinct clinical procedures: BloodTest (centrifugation & optical flow cytometry), UrineTest (photometric dry chemistry & sediment microscopy), ImagingTest (radiation calibration & DICOM reconstruction). 

// Dynamic Polymorphic Dispatch:
const tests = [new BloodTest(), new UrineTest(), new ImagingTest()];
for (const test of tests) {
  // Runtime polymorphism executes subclass-specific method:
  await test.processTest();
}
Concept E

Interface-like Contract

JavaScript does not feature native interfaces. We implement a formal contract using IReportGenerator base class that enforces generateReport() and formatResults() methods. LabReport inherits and adheres strictly to this contract. 

class IReportGenerator {
  generateReport(data) {
    throw new Error("Interface contract method not implemented");
  }
}
class LabReport extends IReportGenerator {
  generateReport(data) { ... }
}
Concept F

Custom Exception Handling

Custom JavaScript error classes extending native Error: PatientNotFoundError, InvalidSampleError, TestNotFoundError, and InvalidResultError. Used with try-catch blocks to render friendly toast alerts. 

class PatientNotFoundError extends Error {
  constructor(msg = "Patient record not found") {
    super(msg);
    this.name = "PatientNotFoundError";
  }
}
Concept G

Collections & State Management

Structured JavaScript arrays and dictionary maps manage collections of: patients, tests, samples, results, and reports, with seamless bi-directional serialization to browser LocalStorage. 

class LabDataManager {
  #patients = []; // Encapsulated collection
  #tests = [];
  #samples = [];
  #results = [];
  #reports = [];
}
